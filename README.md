STL / 3MF ファイルを **リアルタイム PBR** で高品位にプレビューする VSCode 拡張です。`.stl` / `.3mf` を開くとこのビューアで表示され、ファイルが書き換わると**視点を保ったまま自動で再読込**します。CAD やスクリプトで形を作りながら、3D プリントしたときの見え方を横で確かめられます。

## 機能

- **PBR 描画**: 環境光（IBL）＋影付きのキーライト＋床下からの補助光＋カメラに付けた弱い光、ソフトシャドウ、アンビエントオクルージョン（隅や接地部の陰り）、アンチエイリアス
- **材質プリセット**: PLA マット / PLA / PLA シルク / PETG / PETG クリア / レジン / カーボン入り / アルミ ＋ 色ピッカー
- **ライトの調整**: 「ライト」でキー・補助・環境光・カメラの光の強さをスライダーで変えられます（「既定に戻す」あり）
- **背景**: スタジオ（明）/ スタジオ（暗）
- **自動リロード**: ファイルが書き換わると、書き込みが終わるのを待ってから読み直します
- **滑らかな陰影**: 設定した角度未満で接する面は滑らかに、それ以上は折れ目としてシャープに描きます
- **寸法表示**: 外寸（X × Y × Z, mm）と三角形数を表示します。ファイルの Z 軸を上向きとして表示します
- **ファイルの色**: バイナリ STL の色や、3MF のフィラメント・材質の色があればその色で塗ります。ファイルの中の色ごとに、表示する色を変えることもできます（ファイルは書き換えません）
- **色のコピー**: ファイル名と色（16 進・RGB）をテキストでクリップボードにコピーできます
- **見た目の記憶**: 材質・色はファイルごとに、背景とライトは全体で覚えます

## 使い方

- エクスプローラで `.stl` / `.3mf` を開きます。またはコマンドパレット / エクスプローラの右クリックで `JP STL Viewer: STL / 3MF をプレビューで開く` を選びます
- 左ドラッグで回転（裏返しても止まらず、どの向きにも回せます）、右ドラッグでパン、ホイールでズーム、`F` または「全体表示」で視点を戻します
- 「色」を押すと、色ピッカー・16 進の入力欄・「ファイルの色を使う」・「色をコピー」が開きます
  - 色付きのファイルでは、ファイルの中の色が表面積の多い順に並び、1 色ずつ変えたり元に戻したり（↺）できます
  - 「色をコピー」は、変えた色があれば「元の色 → 新しい色」の一覧を、無ければ色の一覧をコピーします

`.stl` / `.3mf` を別の拡張で開いてしまう場合は、ファイルを右クリック →「Open With…」→「JP STL Viewer」→「Configure default editor」で切り替えます。

## 設定

| 設定 | 既定値 | 説明 |
|---|---|---|
| `jpstlviewer.creaseAngle` | `30` | この角度（度）未満で接する面どうしは滑らかに陰影を付けます。0 でファイルどおりのフラット陰影になります |
| `jpstlviewer.floatRatio` | `0.05` | モデルを床から浮かせる量（外接球の半径に対する割合）。0 で接地します |

## 色付きの STL について

STL の色は正式な規格ではありません。この拡張は、多くのツールが使うバイナリ STL の慣習（ヘッダの `COLOR=` と、三角形ごとの 15 ビット色）に対応しています。ヘッダに `COLOR=` が無いファイルは色なしとして扱います。ASCII STL には色を入れられません。

## 3MF について

- ファイルに入っているオブジェクトを、配置（ビルドの位置・回転）どおりに 1 つの形にまとめて表示します。Bambu Studio などで複数のプレートに並べたファイルは、全プレート分が並んで見えます
- 別ファイルに分けた部品（Bambu Studio / OrcaSlicer が使う Production 拡張の `p:path`）も読みます
- 形ではないもの（3MF の `type` が `support` などのオブジェクト、Bambu Studio / OrcaSlicer のモディファイア・負の体積など）と、「印刷しない」にしたオブジェクトは描きません。PrusaSlicer のモディファイアは見分けられず、形として描きます
- 色は次の順で決めます
  1. Bambu Studio / OrcaSlicer の 3MF: オブジェクト・部品に割り当てたフィラメントの色（3MF の材質より優先します）
  2. それ以外: 3MF の材質（`basematerials` の `displaycolor`、`colorgroup` の色）。色の無い面は灰色で表示します
- スライサーの「塗り分け（ペイント）」の色には対応していません
