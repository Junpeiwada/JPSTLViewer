STL を **リアルタイム PBR** で高品位にプレビューする VSCode 拡張。エクスプローラで `.stl` を開くとこのビューアで表示され、スクリプトで STL を書き出し直すと**視点を保ったまま自動で再読込**する。build123d などで形を詰めながら、横で仕上がりの見え方を確かめる用途を想定している。

## 機能

- **PBR 描画**: 環境光（RoomEnvironment を IBL に焼いたもの）＋影付きのポイント光源（キー）＋床下からの補助光、ソフトシャドウ（PCF）、GTAO（隅や接地部の陰り）、MSAA、PBR Neutral トーンマッピング
- **材質プリセット**: PLA マット / PLA / PLA シルク / PETG / PETG クリア / レジン / カーボン入り / アルミ ＋ 色ピッカー
- **ライトの調整**: パネルの「ライト」でキー・補助・環境の強さをスライダーで変えられる（全ファイル共通で記憶。「既定に戻す」あり）
- **背景**: スタジオ（明）/ スタジオ（暗）。床は霧で背景に溶かして地平線を見せない
- **自動リロード**: STL の更新を監視し、書き込み完了（バイナリはヘッダの三角形数とファイル長の一致、ASCII は `endsolid`）を待ってから読み直す
- **滑らかな陰影**: 設定した角度未満で接する面は法線を平均する（曲面はなめらか、折れ目はシャープ）
- **座標**: STL の Z 上向き（CAD の慣習）として表示し、床から少し浮かせて置く（量は設定）。下部に外寸（STL の X × Y × Z, mm）と三角形数を表示
- **色パネル**: パネルの「色」を押すと、色ピッカー・16 進の入力欄・「STL の色を使う」・「色をコピー」が開く。「色をコピー」で `jp_knob16_knob/knob.stl の色: #d9773a（RGB 217, 119, 58）` の形をクリップボードに入れる（パスはワークスペースからの相対）。AI に貼って「このパーツをこの色に」と頼む用
- **STL の色**: バイナリ STL に色が埋め込まれていれば（下記）その色で塗る。色付きのときだけ「STL の色」チェックが出て、外すと色ピッカーの色に戻せる
- **STL の色ごとの調整**: STL の色で塗っているとき、色パネルに STL の中の色が表面積の多い順に 1 行ずつ並ぶ（ピッカー・16 進の入力欄・元の色と表面積の割合・元に戻す ↺）。変えた色は表示だけに効き、STL ファイルは書き換えない（ファイルごとに覚える。ほかのファイルには引き継がない）。「色をコピー」は、変えた色があれば `<パス> の色の変更:` に続けて `#dedede → #d4d4d4（RGB 212, 212, 212）` を 1 行ずつ、無ければ STL の色の一覧をコピーする。どの範囲に反映するか（ほかの STL・色の定数）は受け取った側（AI）が決める
- **見た目の記憶**: 材質・色・「STL の色」・STL の色の置き換えは STL のパスごとに覚える（最近の 500 件）。初めて開く STL は直前に使った見た目で始まる。背景とライトは全ファイル共通（いずれも globalState）

操作: 左ドラッグで回転、右ドラッグでパン、ホイールでズーム、`F` または「全体表示」で視点を戻す。

コマンドパレット / エクスプローラの右クリック: `JP STL Viewer: STL をプレビューで開く`

## 設定

| 設定 | 既定値 | 説明 |
|---|---|---|
| `jpstlviewer.creaseAngle` | `30` | この角度（度）未満で接する面どうしは滑らかに陰影を付ける。0 で STL どおりのフラット陰影 |
| `jpstlviewer.floatRatio` | `0.05` | モデルを床から浮かせる量（外接球の半径に対する割合）。大きさに比例するので、どのモデルでも同じ浮き具合に見える。0 で接地 |

## 設計メモ

### ライティング

キーライトはポイント光源で、光度はモデル中心での照度がスライダーの値になるよう距離² を掛けて決める。既定はキー 1.6・補助 1.0・環境 0.3。
床下の補助光は影を落とさず、底面・裏側に届く。床は上向きの片面で、床下に回り込むと床は消えて底が見える。全体の露出は `src/webview/main.ts` の `toneMappingExposure`、ライトの既定値は `src/webview/looks.ts` の `DEFAULT_LOOK` で変える。

### STL に色を入れる方法

STL の色は正式な規格ではなく、バイナリ STL の慣習として次の形で入れる（Three.js の STLLoader の解釈に従う）。

- 80 バイトのヘッダのどこかに `COLOR=` ＋ R・G・B・A の 4 バイト → ファイル全体の既定色。**これが無いと色なしとして扱う**
- 三角形ごとの予備 2 バイト（リトルエンディアン）: 最上位ビットが 0 なら固有色で、`r | g<<5 | b<<10`（各 5 ビット）。最上位ビットが 1 ならヘッダの既定色
- ASCII STL には色を入れられない。build123d の `export_stl` は色を書き出さないので、色付きで出すなら後から書き込むか 3MF を使う

### webview への STL の渡し方

拡張側で読んだ STL のバイト列を `postMessage` で webview に渡す。Three.js は esbuild で `media/webview.js` に同梱しており、オフラインで動く。

## 開発

```bash
npm install
npm run compile     # 型チェック（拡張・webview）→ webview を esbuild で束ねる
npm run watch       # webview の監視ビルド
```

VSCode でこのフォルダを開いて F5（拡張機能開発ホスト）で動作確認。

## インストール（VSIX）

```bash
npm run install-local   # コンパイル → VSIX 生成 → この VSCode にインストール（一発）
```

VSCode から実行する場合は ⌘⇧P →「Tasks: Run Task」→「npm: install-local」。
インストール後はウィンドウをリロード（⌘⇧P →「Developer: Reload Window」）すると反映される。

`.stl` の既定エディタが他の拡張になっている場合は、STL を右クリック →「Open With…」→「JP STL Viewer」→「Configure default editor」で切り替える。
